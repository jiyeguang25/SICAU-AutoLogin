## v2.2 —— 界面重做：下拉能用了，面板更紧凑

> **本次只发 Windows 版**：包里只有 `SICAU-win-2.2.exe`，没有 apk。
> 安卓端自 v2.1 起暂停更新，最新安卓包仍是 [v2.1](https://github.com/jiyeguang25/SICAU-AutoLogin/releases/tag/v2.1)。

### 改了什么

**1）界面整体重做，配色跟你常用的深色主题对齐**

上一版是 WinForms 默认脸，控件挤在一起、有些字被边框切掉。这一版重画了整个界面层：

- 卡片式分区（设置 / 选项 / 日志各一张卡），圆角、细边框、卡片之间留白；
- **暗色与亮色两套配色**，「界面主题」里可跟随系统、强制亮、强制暗；
- 字号、行高、控件高度统一按 1.5 倍缩放算，高分屏不再挤字。

**2）修掉「字糊成一团」**

双缓冲的离屏位图画布初始 alpha 是 0，ClearType 在透明底上画字会糊。
现在每个自绘控件都先把背景填实再画字。这一条肉眼最明显：页签、按钮的文字从「灰糊」变清晰。

**3）下拉框彻底重写（原来这个是真不能忍）**

旧实现每次点开都 `new Form()` 弹一个独立窗口，点下拉本身不会让那个窗口失活，于是：

- 列表留在屏幕上不消失，再点又叠一个 → **「卡住」**；
- 更早的一版甚至点了没反应。

现在改为**在窗体内部画一个候选列表**：点一下出现，点条目即选中，点窗口任意别处即关，
支持 ↑↓、回车、Esc、滚轮。实测连点三次仍然只有一个列表。

**4）「有线 / 无线」两个页签改成一行三选一**

以前是两个页签强迫你二选一，可笔记本插着网线也可能走无线。
现在是一个下拉：**自动 / 仅有线 / 仅无线**，默认「自动」——每次认证时再看哪块网卡在线，
这也回到了更早版本"可以自动也可以选"的做法。

**5）面板更紧凑**

- 两排按钮并成一排（保存 / 认证 / 检测 ｜ 目录 / 清空 / 换目录 / 卸载 / 关于），
  文字缩短、全名放鼠标提示；中间一条竖线分隔主操作与维护类。
- 「热点频段」原本独占一行、右半边整片空白，现在与四个热点按钮同一行。
- 日志区最小高度略降。

窗口从 **1054×938 缩到 1070×860**（150% 缩放下设备像素）：矮了 78 换算成逻辑像素约 52，
面积小 7%，但设置了少一行、按钮少一排。

### 兼容性

- 配置文件、日志位置、开机自启方式都没变，**直接覆盖旧 exe 即可**。
- 以前存 `mode=wifi` / `mode=wired` 的配置照旧认识；「自动」是新增的默认值。
- 密码加密方式没变（仍是 DPAPI），已加密的配置不用重新输密码。
