# 校园网自动认证 · v2.4（Windows）

这一版只做一件事：**把托盘菜单补齐**。

## 为什么做

上一版把「复制日志」「检查更新」放进了主界面。但很多人会选「认证成功后留在托盘监测」——
之后就再也不打开主界面了。对他们来说，主界面里的按钮等于不存在：出了问题想发日志，
得先想起来「右键托盘 → 显示窗口」，再滚到底部找按钮。

现在右键托盘图标，这三件事直接就能做：

- **复制日志** —— 和主界面那个「复制」完全一样，把整段带时间戳的日志放进剪贴板
- **打开配置目录** —— 配置和日志都在这个目录里，反馈问题时方便直接找文件
- **检查更新** —— 不用打开窗口就知道是不是最新版；有新版会问你要不要打开下载页

托盘菜单现在是这个顺序：

```
显示窗口
─────────
立即认证
检测状态
─────────
开热点 / 关热点 / 热点状态
─────────
复制日志 / 打开配置目录 / 检查更新      ← 本版新增
─────────
退出
```

## 其他

- 版本号 2.4（`FileVersion=2.4.0.0`），与发布包版本一致：`SICAU-AutoLogin-v2.4.zip` 里就是 `SICAU-win-2.4.exe`，程序版本 2.4。
- 安卓版仍停在 v2.1，不再维护（见仓库首页说明）。

## 实测记录

- 托盘菜单项数 14（含 4 条分隔线），三项新入口点击处理器均已挂上。
- 「检查更新」实测走真实网络打 GitHub Releases：返回「已是最新版（2.4）」，状态栏与日志同步显示。
- 版本比对闭环：线上 latest = v2.4，本机 2.4 → `HasNewer=False`。

**下载**：`SICAU-AutoLogin-v2.4.zip` → 解压 → 双击 `SICAU-win-2.4.exe`（免安装、无依赖）
