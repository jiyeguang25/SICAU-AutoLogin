# 校园网自动认证 · v2.3（Windows）

这一版没有新功能列表式的堆料，全在补「**新同学第一次用会卡在哪**」。
一句话：出问题时它开始告诉你要做什么，而不是甩你一个名词。

## 认证失败时会告诉你下一步怎么办

以前弹窗只给结论：`密码错误`、`在线设备数已达上限`。
知道怎么办的人一看就懂，第一次遇到的人只能猜。这一版在结论下面补一句具体动作：

| 它说 | 现在还会说 |
|---|---|
| 密码错误 | 确认是不是最近改过密码（比如在学校统一身份认证平台改过）：重新输入密码，点「保存」再点「认证」 |
| 在线设备数已达上限 | 同一账号一般只允许一台设备在线：先把手机或平板的校园网断掉，再点「认证」 |
| 欠费 / 停机 | 先去充值 / 到网络中心或自助服务恢复，之后才能认证 |
| 打开认证页失败 | 多半是还没接入校园网：先连 `i_sicau` 或 `i_sicau_wifi6`，插网线的确认网线通 |

手动点「认证」失败时，同样的建议也会写进日志区。

## 日志可以一键复制

日志区多了一个**「复制」**：整段日志（含时间戳）进剪贴板，直接贴给维护的人。
以前同学报「不好使」，现在能给出能定位的东西。

## 从没设置过热点的机器会自动填一组

新装的 Windows 没有热点配置，界面上「热点名称/密码」是空的，点「开热点」只会得到一句系统报错。
这一版在发现读不到热点配置、且两栏都空着时，会自己编一组：

- 名称 `SICAU-` + 4 位，例如 `SICAU-dd9n`
- 密码 10 位，**去掉了 l / i / o / 0 / 1** 这种手输容易认错的字符

点「保存」就写进系统生效，不需要再去系统设置里翻。

## 每 7 天静默查一次更新

「检查更新」原来藏在「关于」里，大多数人一辈子不会点，于是永远停在旧版本。
现在启动时若距上次**成功**检查超过 7 天，会在后台问一次：

- 只有真的**有新版本**才写一行日志 + 一个托盘气泡
- 检查失败**一律静默**（校园网里 api.github.com 常常不通），不会刷屏
- 手动在「关于」里查过也算一次，不会重复打扰

## 崩了也有交代

以前程序意外出错，用户那边只表现为「点了一下、窗口没出来、进程没了」。
现在任何未处理异常都会：写进日志 → 弹一句能看懂的中文提示 → 告诉你日志在哪。
