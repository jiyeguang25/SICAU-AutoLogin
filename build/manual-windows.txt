H1|一、这个工具解决什么问题
P|在学校里，每次开机、每次换到新的教学楼或宿舍，都要手动打开认证页面、输入学号和密码，才能上网。这个工具把这一步自动化了。
B|开机后自动检测网络状态，没认证就自动提交账号密码完成认证
B|可以完全静默地在后台把事办完，也可以弹个窗口告诉你结果
B|自动帮你连上指定 WiFi，不用再手动点浏览器
B|附带一个小功能：把电脑变成一个 WiFi 热点，分享给手机或平板
N|它只做「自动填表提交」这一件事。你的密码只保存在本机配置文件里，不会上传到任何服务器。

H1|二、30 秒快速上手
P|只需要三步，之后开机就不用再管了。
B|第一步：双击 SICAU-win-1.7.exe 打开程序（文件名里的 1.7 就是版本号，以后看到数字更大的就是新版）
B|第二步：在「学号」「密码」两栏填好你的校园网账号
B|第三步：标题栏右上角的「认证成功后」保持默认的「自动退出程序」，点「保存并应用」
P|看到状态栏提示「已保存，开机自动认证已启用」，就配置完成了。

H1|三、安装与首次配置
H2|3.1 放在哪里
B|建议放在一个固定的目录里，整个文件夹一起搬就行（程序、配置、日志都在里面）
B|程序放在哪都能跑。用界面底部的「安装到其他目录」可以换个地方，它会自动搬家，并把开机自启一起指过去
B|你的电脑上程序就在项目文件夹里，文件名是 SICAU-win-1.7.exe
H2|3.2 首次运行向导
P|第一次打开程序会弹出一个向导窗口。上半部分是「环境检测」，自动列出你的网络环境；下半部分让你填账号。
T|检测项;含义;不正常时怎么办||无线网卡;有没有可用的无线网卡;显示「未检测到」说明机器没有无线网卡，热点功能用不了，但认证不受影响||无线连接;当前连着的 WiFi 名称和 IP;显示「未连接」而你又用无线，说明得先连上校园 WiFi||有线连接;有线的 IPv4 地址;显示「未连接」而你又用有线，检查一下网线||网络状态;「已联通」表示现在能上网;「未认证」是正常的，认证完就会变
P|填好学号和密码后点「开始使用」即可。如果暂时不想填，点「稍后手动设置」，回到主界面再填。

H1|四、主界面说明
P|主界面最上面是「有线 / 无线 / 热点」三个页签，点哪个就只看那一页的设置。标题栏右上角固定放着「界面主题」和「认证成功后」两个下拉框，切页签也不影响它们。
P|设置表格里每一行长这样：左边一个名称，右边一个输入框，再往右可能还有一格。左下角是状态文字，下面一大块是运行日志，最底下一排是按钮。

H1|五、两种开机模式（重点）
P|标题栏右上角的「认证成功后」决定了认证跑完之后怎么收场，这是这个工具最重要的一个选项。
T|模式;认证成功后发生什么||自动退出程序（默认）;直接结束进程。全程没有窗口、没有托盘图标，最安静。窗口里点「立即认证」或者点窗口右上角的叉号，也一样直接退出||留在托盘监测;收进右下角托盘继续在后台盯着，按「检查周期」定期复检，断线了自动补认证
H2|5.1 「自动退出程序」时没有「检查周期」
P|当「认证成功后」选「自动退出程序」时，「检查周期」会自动变灰、数值清零。
N|原因很简单：这个模式是「认证一次就走」，进程都不在了，自然不存在「每隔多久复查一次」这回事。只有选「留在托盘监测」时，程序才会在后台按你设的周期自动复检，这时那一项才会重新变得可以编辑。
H2|5.2 两种模式的收尾按钮
P|开机认证失败时，程序会弹一个小窗口告诉你失败原因，窗口上有「退出程序」和「留在托盘」两个按钮，这一次点哪个都行，不会改掉你的设置。

H1|六、托盘与图标状态
P|托盘图标（任务栏右下角）会随着连接状态变色，扫一眼就知道通没通。
T|图标底色;含义||蓝色;已连上校园网（认证成功，或者网络本来就是通的）||红色;未连上（认证失败，或者还没探测到）
P|另外，程序本体、窗口标题栏和桌面那个 EXE 的图标，是绿色底的 WiFi 图标。绿色指的是「程序图标」，蓝红指的是「托盘状态」，两者不是一回事。
B|双击托盘图标：打开主界面
B|右键托盘图标：可以直接「立即认证」「检测状态」「开热点 / 关热点」
B|鼠标悬停在托盘图标上：会显示「已连上」或「未连上」

H1|七、自动连接 WiFi
P|「WiFi 名称」这一栏决定程序要不要顺带帮你连 WiFi。点右边的「扫描」按钮，程序会主动扫一次周围的网络。
B|用的是系统 wlanapi 主动扫描，不是读缓存，所以能看到周围全部可见网络，而不只是你已经连上的那一个
B|扫描大约需要 3 秒，按钮会变成「扫描中」
B|结果按信号强弱排序，你当前连着的那个排在最前面
B|同一个名字的多个接入点会自动合并成一个

H1|八、把电脑变成热点
P|认证上网之后，可以把电脑的网络通过 WiFi 分享给手机、平板。
B|热点名称和密码可以直接在界面上改，改完点「保存并应用」
B|只有内容真的变了才会去改热点。因为系统改热点配置会重启热点、把已连设备踢下线，所以没改动就不会无谓地打扰你
B|点「热点状态」可以看到已连设备数，以及每台设备的 IP 和 MAC
B|热点连不上时点「修复热点」，它会自动帮你修
N|注意：手机搜到的热点名可能会带上电脑名后缀（例如 DESKTOP-XXXX 2154），这是 Windows 的行为，属于正常现象。

H1|九、界面主题
B|跟随系统（默认）：系统是深色就深色，系统是浅色就浅色
B|浅色：白色卡片配浅灰底
B|深色：深灰底、暗色卡片，窗口标题栏也会跟着变黑
P|改完立刻生效，不用重启程序。

H1|十三、常见问题
H3|认证显示成功，但还是打不开网页？
B|浏览器可能缓存了旧的认证跳转页面，换个页面或者刷新一下
B|确认连的是校园网 WiFi，而不是别的网络
B|点「检测状态」看看是不是真的通了
H3|开机自启好像没生效？
B|界面上的「开机自动认证」要勾上，并且点过一次「保存并应用」
B|程序被移动过位置的话，自启快捷方式会失效。用「安装到其他目录」重新部署一次
B|想手动确认：按 Win+R 输入 shell:startup 回车，里面应该有一个「校园网自动认证」的快捷方式
H3|杀毒软件报毒 / 程序文件不见了？
B|这是早期版本用「计划任务」做自启导致的误报，新版已经改成「启动」文件夹快捷方式，不再触发
B|如果程序文件真的被删了，重新从原来的位置复制一份 EXE 出来即可，配置和账号都还在
H3|连上校园网后自动弹出的登录页能不弹吗？
B|那个弹窗是 **Windows 自己**弹的（系统会去探测能不能上网，校园网把它劫持到登录页），不是本程序
B|办法一（推荐）：把「开机自动认证」勾上，让本程序抢先认证完，系统探测通过了自然就不弹
B|办法二：勾上「不自动弹校园网登录页」→ 点「保存并应用」。这个要管理员权限，会问你要不要重开一次程序。生效要断开重连一次 WiFi 或重启
B|代价：以后系统不再提示你去登录，**登录完全靠本程序**；WiFi 图标上可能挂个感叹号，个别机器会因为「这网没互联网」主动断开 WiFi。想还原就把勾去掉再保存一次
H3|托盘图标一直是红色？
B|说明当前没连上校园网。点「立即认证」试一次
B|刚开机时程序需要几秒钟探测，稍等片刻图标会变色
B|如果一直是红色且上不了网，点「检测状态」看详细原因
H3|热点连不上？
B|点「修复热点」
B|把「热点频段」改成「仅 2.4GHz」再试，部分手机不认 5GHz 热点
H3|改了校园网密码之后怎么办？
B|在主界面把新密码填进「密码」栏，点「保存并应用」
H3|换了宿舍或教学楼，网络环境不一样了？
B|点「扫描」重新选一个当前能连的校园 WiFi，再保存
H3|想彻底关掉自动认证？
B|把「开机自动认证」的勾去掉，点「保存并应用」

H1|十四、卸载
