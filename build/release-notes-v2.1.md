## v2.1 —— 密码不再明文躺着，配置里也不再写死学校域名

> 说明：这次是**包版本 v2.1**，里面装的是**程序版本 2.0**
> （`SICAU-win-2.0.exe` / `SICAU-android-2.0.apk`）。
> 版本错位是老规矩：包版本 = 程序版本 + 0.1。

### 改了什么

**1）密码不再明文存盘**

以前 `%APPDATA%\SICAU-AutoLogin\config.conf` 里那一行是 `password=你的密码`，谁都看得见。
现在改成加密：

- **Windows** 用 DPAPI，密钥由**你这台电脑的这个 Windows 账户**派生 ——
  把配置文件拷到别的电脑、或者换个人登录，都解不开。
- **安卓** 用 Android Keystore 里的 AES 密钥，密钥不出安全硬件。
- 老的明文配置**会自动迁移**：第一次运行新版时读进来、加密写回，你不用做任何事。
- 想确认自己存的是什么？密码框下面有「显示密码（本机加密保存）」勾选框，勾上才显示。

也就是说：**现在把 `config.conf` 发给别人，里面已经没有密码了。**
（日志、账号这些还是别整个文件夹外发，原因见 README。）

**2）「关于」里能检查更新了**

以前想知道有没有新版只能自己来仓库看。现在打开「关于」→「检查更新」，会去 GitHub Releases
查最新版本，有新版本就把按钮变成「打开下载页」。

- **只在你点的时候才联网**，不后台轮询、不静默下载、不自动安装。
- 联网失败（断网、GitHub 限流）会给一句人话，不会卡界面。

**3）学校域名 / WiFi 名 / 端口不再散落在代码里**

这类「学校哪天改了就得改代码重新发版」的常量，全部收敛到 `Site.cs`（Windows）
和 `Site.java`（安卓）两个文件里。**对使用没有影响**，好处是下次学校换域名时只改一处。

### 修了什么

**「检查更新」永远说你有新版本**

这个 bug 是这一版自己引入、又在发布前抓掉的：发布包的 tag 是 `v2.0`，而包里装的程序是 `1.9`，
检查更新的代码直接拿 tag 和程序版本比大小 —— `2.0 > 1.9`，所以**每个已经装了最新版的人都会被告知"有新版本"**，
点进去下载页给的东西和手里一模一样。

现在改成从附件名里取程序版本（`SICAU-win-2.0.exe` 里的 `2.0`），取不到才退回 tag。
代价是：如果你装的是**更早**的版本，提示里的版本号会显示成程序版本（更准确），不是包版本。

### 下载

| 平台 | 文件 | 怎么装 |
|---|---|---|
| Windows 10 / 11 | `SICAU-win-2.0.exe` | 双击就能跑，免安装、无依赖（单文件） |
| Android 6.0+ | `SICAU-android-2.0.apk` | 传到手机点开安装 |

**先解压 zip 再双击**里面的 exe（这样不会触发 SmartScreen 的"发布者未知"提示）。
`下载说明.txt` 里有每个文件的 SHA256，可以核对没被掉包。

> **建议解压到固定目录，别长期放在「下载」文件夹里。**
> 想更省事可以用安装模式：`SICAU-win-2.0.exe --install`
> —— 它会把程序复制到 `%LOCALAPPDATA%\Programs\SICAU-AutoLogin`，并把开机自启指过去。

> **升级注意（Windows）**：新版文件名变了（`1.9` → `2.0`），
> 直接运行新版即可；如果旧版还在托盘里，先右键退出，再让新版接管开机自启
> （程序启动时会自己校正快捷方式指向）。
