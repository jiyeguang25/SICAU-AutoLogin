## 校园网自动认证 v1.7 —— Windows + 安卓

把校园网的网页认证自动化：连上校园网后自动填表提交，不用再手动点登录页。

### 下载

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows 10 / 11 | `SICAU-win-1.7.exe` | 双击就能跑，**免安装、无依赖**（单文件，约 145 KB） |
| Android 6.0+ | `SICAU-android-1.7.apk` | 传到手机点开安装（约 77 KB） |

### 这版有什么

**Windows**

- 顶部「有线 / 无线」页签直接决定连哪张网卡（没有容易误判的「自动」了）
- 「认证成功后」可选**自动退出程序**（最安静，不留后台）或**留在托盘监测**（按周期复查，断线自动补认证）
- 「热点」页签：开/关热点、看已连设备、修热点
- 仿 Win11 的浅色/深色主题
- **不自动弹校园网登录页**：关掉 Windows 的强制门户探测（需要管理员权限）
- 「关于」里有版本和运行环境

**安卓**

- **学校那两个 WiFi 名做成了按钮**（`i_sicau_wifi6` / `i_sicau`），点一下就连，不用打字
- 也可以点输入框从列表里挑（当前连着的 → 学校这两个 → 扫到的周围 → 你手打过的）
- **读不到 WiFi 名字也能正常用**（认网络看网卡 IP，不看名字）；点界面上的 WiFi 状态文字可以看诊断
- 日志自动滚到最新一条
- 「减少『登录到网络』打扰」会告诉你怎么关掉系统那条登录提醒

### 说明

- 密码**只保存在本机**，不会上传到任何服务器
- 本工具只是代替你手动点一次登录页，不做任何破解；**与学校官方无关**
- 只在你自己的账号上使用，遵守学校网络使用规定
- 本项目针对**四川农业大学**校园网（门户 `portal.sicau.edu.cn`）。别的学校要改门户地址和网关参数

### 已知限制

- 安卓 10 起不允许应用静默切换 WiFi，必须你在系统弹窗里点一下确认
- 安卓 12 起系统只让应用看到「连过的」WiFi，扫描列表可能很短
- 安卓上的「登录到网络」提醒是系统的强制门户检测发的，第三方应用关不掉（程序里给了关通知的办法）
